    Publication reproduction coverage¶

    Publication-scale systems are the strongest software-path tests in q2mm because they combine many QM Hessians, full + OPT force-field composition, frozen parameters, QFUERZA initialization, evaluation, optimizer entry, and persistence. They do not all reproduce the complete source objective.

    The canonical machine-readable records are in q2mm.benchmarks.publications; the source-linked evidence is Publication Force-Field Coverage.

    Current matrix¶

    The following is a deterministic projection of every canonical system/profile/starting-point record, including blocked and historical rows. Provisionable means the recorded problem can be constructed when its required inputs are supplied; it does not mean those inputs are bundled, that optimization converges, or that the source study is exactly reproduced.

    Read the claim vocabulary alongside each row. Target dispositions mean: implemented is populated in this profile; available has source values but is not populated; omitted is not populated; blocked has unresolved input or execution requirements. They are not interchangeable. An empty membership means no authoritative training cases are recorded, not a successful zero-case problem.

    The committed Markdown and built site share the same projection. Refresh it after changing canonical metadata with python scripts/gen_publication_pages.py --write; run the command without --write to check freshness. The docs build and core tests also reject stale snapshots. This check verifies documentation consistency, not scientific validation.

    Compatibility profile¶

    The five TS systems use repository-geometry-eigenmatrix-v1. It preserves the repository bond, angle, and full-eigenmatrix observations and weights exactly. Those weights are not silently rewritten to the general source tolerances, and selecting published versus QFUERZA values changes the starting vector—not the observations.

    Ferrocene additionally names wahlers-ferrocene-seven-structure-v1, a published-start, seven-ground-state partial profile. The exact scan and QFUERZA rows remain blocked.

    Typed but unsupported source terms¶

    Grouped relative energy and equilibrium-parameter tethers execute in the Python and JAX objective paths. Relative enthalpy, atomic charge, direct ESP, and constrained scan observations have canonical identities and fingerprints, but raise typed errors when a backend cannot calculate the required property. Q2MM does not replace them with potential energy, charges, optimizer bounds, or another surrogate.

    Historical force-field-only records¶

    Historical force-field-only records are included in the generated matrix, not counted as executable successes. Candidate citations and unverified file-to-paper mappings are explained in the blocked inventory; no authoritative QM training problem is available.

    Executable proof¶

    The source-only scripts under examples/publication/ run each provisionable study through the root application functions. Their bounded mode uses the real case membership and objective, enters the optimizer once, saves a field and manifest, and explicitly makes no convergence claim.

    Numerical optimization claims require a linked canonical record in ericchansen/q2mm-data. Example outputs are not committed to this repository.
